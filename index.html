These are coverage proxies, not a parity score. Nobody can put a meaningful single percentage on "how much of Minecraft is implemented". Most vanilla blocks need no behaviour code, so the block figure understates parity; conversely a registered behaviour may still be incomplete, which overstates it. Treat the direction of travel as the signal, not the absolute numbers.

What each figure means

  • Blocks with behaviour — Blocks registered in the block registry, over every block in the game data. Many vanilla blocks need no behaviour code at all, so this undercounts real parity.
  • Mobs with AI — Mob types with an AI module, over every entity type (which includes projectiles, vehicles and display entities that need no AI).
  • Commands — Command modules implemented, against roughly 75 player-facing commands in vanilla 1.21.

DESIGN FOR THE PATH ENGINE (new file:
crates/pumpkin/src/command/argument_types/nbt_path.rs, sibling to nbt.rs):
- A `PathNode` enum with the same six cases as vanilla's Node subclasses: CompoundChild(String),
  MatchObject(String, NbtCompound), MatchRootObject(NbtCompound), IndexedElement(i32),
  MatchElement(NbtCompound), AllElements. Port each one's getTag/getOrCreateTag/
  createPreferredParentTag/setTag/removeTag body directly from NbtPathArgument.java lines
  155-529 - the logic (negative-index wraparound, empty-list special case in
  AllElementsNode.setTag, MatchRootObjectNode being firstNode-only) is exact and easy to get
  subtly wrong; do not improvise it.
- compareNbt (NbtUtils.java ~line 65): partial match - Compound requires actual.len() >=
  expected.len() and every expected key present in actual with a recursively matching
  value; List (when partial=true) requires actual.len() >= expected.len() and every expected
  element has SOME matching element in actual (not a bijection, duplicates in expected can
  each match the same actual element); primitives use exact equality. This predicate is what
  MatchObjectNode/MatchElementNode/MatchRootObjectNode filter with.
- `NbtPath { original: String, nodes: Vec<PathNode> }` with a hand-written parser mirroring
  NbtPathArgument.parse/parseNode/readObjectNode/readUnquotedName (lines 62-149) - char-by-
  char against crate::command::string_reader::StringReader (peek/peek_with_offset/skip/
  read/read_int/expect/cursor/set_cursor all exist, check the file for exact signatures),
  delegating to SnbtParser::parse_for_commands for `{...}` patterns and erasing (erroring)
  if the parsed tag isn't a Compound.
- Read-only query op (for `/data get`, and the merge/set "from" source in vanilla, though
  you are not wiring `modify` this run): `get<'a>(&self, tag: &'a NbtTag) -> Result<Vec<&'a
  NbtTag>, CommandSyntaxError>`, immutable refs, no aliasing concerns.
- Mutating ops (`get_or_create`, `set`, `remove`, `count_matching`): implement via recursive
  functions that hold at most one &mut borrow scope at a time - fan out into a node's
  children as Vec<&mut NbtTag> (all disjoint by construction: distinct HashMap keys or
  distinct Vec indices via iter_mut()/get_mut()), recurse into each, sum result counts. Do
  not use raw pointers or unsafe; this pattern needs neither.
- ArgumentType impl: `NbtPathArgumentType; type Item = NbtPath;` client_side_parser returns

  crates/pumpkin-protocol/src/java/client/play/commands.rs:211).
